# 高校通用模拟数据本科生转专业申请表（模拟）

文档类型：表格模板  
适用对象：全日制本科生  
可见范围：student  
状态：模拟资料，非正式表格

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 填写学生本人姓名 |
| 学号 | 填写完整学号 |
| 所在学院 | 当前所属学院 |
| 当前专业 | 当前就读专业 |
| 当前年级 | 如 2024 级 |
| 拟转入学院 | 申请转入学院 |
| 拟转入专业 | 申请转入专业 |
| 已修课程平均成绩 | 按教务系统成绩填写 |
| 申请理由 | 说明学习基础、兴趣、职业规划等 |
| 是否受过处分 | 如实填写 |
| 所在学院意见 | 由学院填写 |
| 拟转入学院意见 | 由拟转入学院填写 |
| 教务部门意见 | 由教务部门填写 |

## 附件材料

- 已修课程成绩单。
- 个人申请说明。
- 拟转入学院要求的补充材料。
