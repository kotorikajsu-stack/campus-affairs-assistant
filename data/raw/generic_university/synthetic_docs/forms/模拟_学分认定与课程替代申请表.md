# 高校通用模拟数据学分认定与课程替代申请表（模拟）

文档类型：表格模板  
适用对象：本科生  
可见范围：student  
状态：模拟资料，非正式表格

## 适用情形

学生因转专业、转学、交流学习、培养方案调整等原因，需要申请已修课程学分认定或课程替代的，可填写本表。

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 学生本人姓名 |
| 学号 | 完整学号 |
| 学院和专业 | 当前学院、专业 |
| 原课程名称 | 已修课程名称 |
| 原课程学分 | 已修课程学分 |
| 原课程成绩 | 已修课程成绩 |
| 拟认定课程 | 培养方案中拟替代课程 |
| 拟认定学分 | 申请认定学分 |
| 申请理由 | 说明课程内容相近性 |
| 任课或课程负责人意见 | 由课程负责人填写 |
| 学院审核意见 | 学院填写 |
| 教务部门备案 | 教务部门填写 |
