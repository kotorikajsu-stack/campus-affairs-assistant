# 高校通用模拟数据本科课程成绩复核申请表（模拟）

文档类型：表格模板  
适用对象：全日制本科生  
可见范围：student  
状态：模拟资料，非正式表格

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 学生本人姓名 |
| 学号 | 完整学号 |
| 学院 | 学生所在学院 |
| 专业班级 | 当前专业班级 |
| 课程名称 | 申请复核课程 |
| 课程代码 | 教务系统课程代码 |
| 任课教师 | 任课教师姓名 |
| 原成绩 | 教务系统显示成绩 |
| 申请复核理由 | 说明疑问点 |
| 学生签名 | 本人签名 |
| 学院审核意见 | 学生所在学院填写 |
| 开课学院复核意见 | 开课学院填写 |

## 复核范围

成绩复核主要核查漏评、累计分错误、登分错误等情况。
