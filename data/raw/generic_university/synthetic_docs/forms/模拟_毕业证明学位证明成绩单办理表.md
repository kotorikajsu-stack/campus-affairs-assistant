# 高校通用模拟数据毕业证明、学位证明、成绩单办理表（模拟）

文档类型：表格模板  
适用对象：在校生、毕业生  
可见范围：student  
状态：模拟资料，非正式表格

## 可办理事项

- 中文成绩单。
- 英文成绩单。
- 在读证明。
- 学籍证明。
- 毕业证明。
- 学位证明。

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 申请人姓名 |
| 学号 | 在校或毕业时学号 |
| 身份证号后四位 | 用于身份核验 |
| 学院 | 所在或毕业学院 |
| 专业 | 所在或毕业专业 |
| 申请材料类型 | 成绩单、证明等 |
| 份数 | 需要办理份数 |
| 用途 | 升学、就业、出国等 |
| 领取方式 | 现场领取或邮寄 |
| 联系方式 | 手机号或邮箱 |
