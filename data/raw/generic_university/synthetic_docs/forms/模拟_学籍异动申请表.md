# 高校通用模拟数据本科生学籍异动申请表（模拟）

文档类型：表格模板  
适用对象：全日制本科生  
可见范围：student  
状态：模拟资料，非正式表格

## 适用事项

本表适用于休学、复学、退学、保留学籍、延长学习年限等学籍异动事项。

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 学生本人姓名 |
| 学号 | 完整学号 |
| 学院 | 所在学院 |
| 专业班级 | 当前专业班级 |
| 异动类型 | 休学、复学、退学、保留学籍等 |
| 申请原因 | 如实说明申请原因 |
| 起止时间 | 休学或保留学籍需填写 |
| 证明材料 | 医院证明、入伍通知书等 |
| 家长或监护人意见 | 按学院要求填写 |
| 学院审核意见 | 学院填写 |
| 教务部门意见 | 教务部门填写 |
