# 高校通用模拟数据本科课程缓考申请表（模拟）

文档类型：表格模板  
适用对象：全日制本科生  
可见范围：student  
状态：模拟资料，非正式表格

## 表格字段

| 字段 | 填写说明 |
|---|---|
| 姓名 | 学生本人姓名 |
| 学号 | 完整学号 |
| 学院 | 学生所在学院 |
| 专业班级 | 当前专业和班级 |
| 联系方式 | 本人手机号 |
| 课程名称 | 申请缓考课程 |
| 任课教师 | 任课教师姓名 |
| 考试时间 | 原定考试时间 |
| 缓考原因 | 因病、突发事件等 |
| 证明材料 | 医院证明或其他证明 |
| 学生签名 | 本人签名 |
| 学院审核意见 | 学院填写 |
| 教务部门备案 | 教务部门填写 |

## 注意事项

申请人应在考试前提交。因突发情况无法提前提交的，应尽快向学院说明并补交材料。
